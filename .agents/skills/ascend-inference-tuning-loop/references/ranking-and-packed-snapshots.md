## Mixed-dtype shared-storage serialization

The same-image KIVI CPU producer reached a real typed packed allocation, then
Torch-NPU's patched serializer rejected mixed-dtype views sharing storage.
This is a persistence failure, not a quantization numerical no-go.

Record live raw/typed-view pointer, storage extent, dtype, offset, shape and
stride **before** creating snapshot copies. Serialize each tensor snapshot with
independent storage when the installed serializer requires it. Independently
check saved bytes against the raw allocation's layout and recorded live binding.
Loaded clone tensors cannot prove live aliasing. Keep source pins, original
packing/reader equations and full case coverage unchanged, preserve the failed
attempt, and validate the small same-image serialization prerequisite before
running the successor matrix. Do not turn this into a rule requiring unrelated
pipelines to clone every tensor.

## CPU budget: concurrency is not core demand

A max_num_seqs=16 setting is request capacity, not evidence that a guest needs
16 CPU cores. Count the actual engine/TP workers, inspect their selected source
and threading controls, and distinguish a conservative template from measured
necessity. Never bypass a frozen resource gate. Register a separate evidence-
supported correctness budget if needed, preserving all numerical/lifecycle
coverage and the fixed cutoff. A slow diagnostic can time out honestly.

For the current seven-core shared host/daemon capacity, a proposed exclusive
TP4 diagnostic may reserve guest4 + MAIN1 + reserve2 while remote preparer CPU
commands are paused; preparer agents may remain active on source/API work.
This is not proof that four cores support formal timing or that a service has
a performance gain. Sum simultaneously admitted work at every common CPU/RAM
ancestor, not independent per-job checks.

## Separate the author's discrete selector from a high-precision output oracle

When the actual author uses BF16 selection arithmetic, FP64 discrete
reselection need not select the same channels/tokens. Freeze original dtype,
division/matmul/GQA reduction order and legal exact ties before the new run.
For the independently justified ANN successor, each q/rq invokes its own
byte-bound author selector outside capture; then recompute complete output,
softmax/alpha/mean from that query's original full K/V in CPU-FP64. Candidate
support/channels/alpha cannot supply this independent feedback oracle.
FP64 reselection stays a labelled diagnostic, not the BF16 author's support
contract. Keep non-tie, full-output, per-head and multi-step gates; preserve
every previous failure rather than retrospectively rewriting it.
