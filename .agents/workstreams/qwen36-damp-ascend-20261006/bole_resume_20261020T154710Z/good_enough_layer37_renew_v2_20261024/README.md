identity only. It does not change the candidate, independent reference,
thresholds, native/bootstrap contexts, controller or resources. No authority,
execution tree, container, Torch calculation or NPU operation was created.

residual-decomposition diagnostics. They should not be rerun to fill the lane.

the compensated frame016 failure and frame001 holdout remain unchanged.

explicit residual step, not MXR's private context repair. This remains a scoped
diagnostic, never 48-layer/model/performance/task acceptance.
