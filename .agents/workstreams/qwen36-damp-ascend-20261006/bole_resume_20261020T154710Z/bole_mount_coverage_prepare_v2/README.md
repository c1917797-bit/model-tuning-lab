## Read-only actual-open gate

The Mounts operand may be a Docker inspect wrapper with stdout, an inspect
object/list, or a standalone Mounts list. MAIN writes that source-qualified
operand; this code never invokes Docker. It imports the *actual source-owned*
qualification validator in a fresh isolated Python process, observes source/
evidence reads, compares indexed exact destinations/ancestor mappings, lists ALL
missing real files, and exits2 on missing/read/validator failure. Only the fixed
source/evidence roots are considered; source-only success does not cover new
32k runtime/operator branches that have not executed.

Default CLI is OFF. The audit rejects writes, process creation, sockets and
native-library loading. Same-image CPU/source review is still required. It
does not authorize devices/containers, repair old tickets or qualify BOLE.
