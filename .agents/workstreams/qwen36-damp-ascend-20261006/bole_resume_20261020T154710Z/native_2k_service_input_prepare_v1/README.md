The exact composition order is geometry renderer → snapshot capacity renderer → this callback renderer. All three transformations invert to the original complete parent bytes. The geometry-added native_geometry argument is an exact required operand, not silently dropped.

A diagnostic qualifier instead requires an explicit complete schema/flag and exact same2048 input with output8,160 or1024 in both qualification and actual profile; boolean-as-integer, wrong caps/schema, missing flag or budget mismatch refuses. Short results cannot authorize a longer scope.
