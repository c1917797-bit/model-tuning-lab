# G1 two-request proposal

This is an isolated advisory packet. No G1 model, scheduler, host, container or device execution has occurred. The passed V6 source, root working copy and qualified numerical references were not edited.

G1 admits exactly two sequential requests, each with the same actual 131-token prompt, two generated tokens and at most one target tree step, followed by a native one-token retirement barrier. `BOLE_G1_MULTI_REQUEST_ENABLE=1` and the exact `bole.c1-two-request-service/v1` source scope are required. All ordinary entry points remain default OFF.

The initial native prefill produces the first output token. The one remaining output forces root-only selected cache publication. Both native first-MTP children are still captured and independently checked; G1 makes no child-acceptance, native-AR, whole-model, accuracy, formal or speedup claim.

Process runner/MTP/after-prefill hooks survive the first retirement. The first request's LM-head and 64-layer bridge are restored, the 48 original native prefill observers are rearmed, then the next actual request is registered with generation 2. The second retirement restores all process hooks before the native barrier. Strong request objects are retained to reject stale owners even if physical slots are reused.

`model_process_calibration.py` calls the original unchanged twelve-case `MC.run` exactly once. Request 2 must use the same worker, runner, model, Torch module, native registration callable and actual convolution operator in the same process. It rechecks all source refs, the entire current loaded-library set and ABI, and reopens the original twelve before/after receipt refs through `MC.validate`. Existing files are never a substitute for this live handle.

The aggregate raw capture contains `requests[2]`, two calibration-acquire proofs and the actual per-layer slot/page tuples. Physical reuse is recomputed and reported as a boolean; reuse is not required from an allocator after exactly two requests. Both registrations, generations and actual independent retirement joins are required regardless of physical reuse.

Each request has separate cache-observation, FA-mapping and loaded-library receipts. One original calibration directory is shared. The original 1 GiB per-rank logical capture ceiling is retained, with a stricter 64 MiB reserve for calibration, both request metadata sets, logits operands and the bounded process journal. The publisher also checks serialized aggregate bytes plus evidence and remaining journal reserve.
