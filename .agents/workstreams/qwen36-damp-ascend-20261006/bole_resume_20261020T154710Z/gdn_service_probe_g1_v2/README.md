This new directory turns the earlier advisory seam into a source builder and
explicit host/server/bridge/consumer wiring. It is prepared-only and has not
been assembled on the host, run in the target image or executed on NPU here.
All frozen G1, AR, GDN kernel/replay/timing and previous integration files stay
unchanged. No new resource admission is implemented: MAIN retains the exact
finite025-derived TP4 physical4..7 -> guest0..3 owner and all original guards.

The first executable scope is the **actual independently passed G1-v2**:
two sequential distinct 131-token requests, two output tokens each, one real
root-only target step per request and native retirement barrier. The builder
pins the actual109479-byte source,131517-byte owner and12221-byte independent
report by their known SHA256s, validates their full successful links, reopens
every donor source and requires all three owned phases stopped/retained.
No future G2 success is invented or required for this narrow probe.
