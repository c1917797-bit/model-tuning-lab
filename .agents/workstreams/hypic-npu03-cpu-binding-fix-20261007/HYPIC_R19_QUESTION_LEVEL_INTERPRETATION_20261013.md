## 计数单位

127个唯一题，每题3次，共381个配对计分响应。原始审计SHA256
40ce887336be3446aa87a8e552fb50d366234fc10006ad5a3140f3dc0df16d9b。
227→219是净少8次正确响应，不是8道独立题稳定失败。

| 题目级现象 | 题数 |
| --- | ---: |
| 三次合计得分提高 | 8 |
| 三次合计得分降低 | 13 |
| 三次合计得分相同 | 106 |
| 基线三次正确性不一致 | 13 |
| HYPIC三次正确性不一致 | 22 |

得分相同不意味着逐次答案或文本相同。仅题index59出现基线3/3正确、
候选0/3正确；它的基线3次自然结束、候选3次达到2048上限。
没有0/3→3/3的稳定改善题。三个重复不足以证明长期稳定性。

逐响应仍是23次对→错、15次错→对。23次退化中，15次伴随
stop→length，6次stop→stop，另外2次基线已length。因此截断相关
现象值得保留，但不是根因证明，不能把全部退化归于输出上限。
改善中也有3次stop→length；length不自动等于评分错误。
不得删除这些响应、延长输出并混用旧分母，或将381次当作381道独立题。
