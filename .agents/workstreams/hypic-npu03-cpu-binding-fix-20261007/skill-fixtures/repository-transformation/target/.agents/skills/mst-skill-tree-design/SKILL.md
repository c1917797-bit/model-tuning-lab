# Skill Tree Design

## Purpose

Create only Skills backed by recurring repository behavior.

## Workflow

1. Start from the core transformation tree.
2. Add a path-specific Skill only with a recorded reason.
3. Give every registry entry a trigger, purpose, and scope.
4. Validate path resolution and uniqueness.
