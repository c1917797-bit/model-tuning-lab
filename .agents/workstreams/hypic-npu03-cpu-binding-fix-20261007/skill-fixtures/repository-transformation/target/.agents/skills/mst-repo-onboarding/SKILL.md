# Repository Onboarding

## Purpose

Identify the product entrypoint, tests, and governing maintainer files.

## Workflow

1. Read `AGENTS.md` and the registry.
2. Inspect `src/app.py`.
3. Select only the Skills required by the task.
4. Record unresolved build or release assumptions.
