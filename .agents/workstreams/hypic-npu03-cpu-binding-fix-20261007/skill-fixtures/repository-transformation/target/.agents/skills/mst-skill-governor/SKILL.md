# Skill Governor

## Purpose

Keep Skill changes evidence-backed, narrow, and discoverable.

## Workflow

1. Record the reusable problem and classification destination.
2. Prefer a narrow existing Skill over a broad new one.
3. Update the registry with the reason for structural changes.
4. Add or update replayable verification.
