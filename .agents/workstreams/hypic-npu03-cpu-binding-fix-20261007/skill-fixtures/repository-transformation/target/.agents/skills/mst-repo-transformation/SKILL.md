# Repository Transformation

## Purpose

Keep the service maintainable through a small canonical Skill tree.

## Workflow

1. Inventory product and agent instruction files.
2. Keep `AGENTS.md` as the short entry point.
3. Update the registry and only justified Skills.
4. Preserve product behavior.
5. Run `./scripts/validate-mst.sh`.
