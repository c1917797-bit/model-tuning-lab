# Transformation Verification

## Purpose

Replay structural checks without claiming untested product behavior.

## Workflow

1. Validate AGENTS.md and adapter boundaries.
2. Validate registry uniqueness and Skill paths.
3. Validate runtime separation and publication policy.
4. Compile and execute the retained product entrypoint.
