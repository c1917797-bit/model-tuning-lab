This is not a scheduler/speculative-serving implementation and supplies no
whole-model numerical qualification. There is no invented hidden/logit
epsilon. Component gates remain their original independently registered
bounds. Complete actual hidden/logit and per-layer differences are retained.

## Executable path

and the actual118c12-frame source/owners/ABI. Typed component argument is:

DENSE090_EXTERNAL_OUTPUT_ENABLE. Readonly rootfs/log cap/cache/RW leaf and

CPU first runs actual native114 API parser/EngineArgs, MTP lazy registry and
checkpoint15-key metadata. The new local34-test suite must also run in that
same owned CPU child before model load. This is not device/class proof.

TP4 canary precedes the actual server. A real tokenizer generates exactly131
IDs. The first genuine HTTP request requests10 tokens, temperature0,
ignoreEOS (diagnostic only). A second one-token native request drives the
first request's actual four-worker retirement; it is not a second BOLE trial.

including randomized engine ID, not guessed from response/header prefixes.

and selected wide-conv extra bytes. It is NOT all-arena/other-request inactive

is passed off as BOLE success. Whole numerical qualification, production,
