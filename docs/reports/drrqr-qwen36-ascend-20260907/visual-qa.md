# Visual QA — DRRQR × Qwen3.6-27B Report

Verdict: PASS

## 检查范围

- HTML：`index.html`
- 全页截图：`rendered/desktop-full.png`
- 截图尺寸：1920 × 8288 px
- 检查方式：将全页截图按纵向 5 段以原始比例独立查看，并静态核对 HTML 中表格、SVG、代码块和 overflow 规则。

## 检查结果

- **滚动报告层级：PASS。** Hero、粘性目录、章节 kicker、H2、卡片标题、正文与页脚层次清楚；章节间距稳定，阅读路径从结论到机制、架构、实验、性能、质量、Dk112、对比、经验、恢复命令和证据入口连续。
- **字号与行距：PASS。** 标题、正文、表格和注释在 1920 px 截图中均可读；正文密度合理。12 px 哈希/审计文本偏小但仍清晰，且符合其辅助信息优先级。
- **对比度与状态色：PASS。** 深色 Hero、白底正文、蓝色层级标签以及绿/橙/红状态语义对比充分；警告和危险 callout 的边框、底色与文字可辨识，没有依赖颜色单独传达结论。
- **表格：PASS。** 多张表格列宽稳定、表头清晰、数字对齐良好，长标题与说明正常换行；未发现单元格重叠、右侧截断或超出内容容器。
- **SVG 原理图：PASS。** DRRQR 原理图节点、箭头、矩阵维度与说明均完整显示；线条和标签清楚，无裁边、遮挡或比例失真。
- **图表标注：PASS。** Dk64/Dk96 条形图包含指标名、方向与精确百分比；图下注明视觉宽度仅表达约 3% 变化尺度，避免把条长误读为绝对性能。颜色与数值状态一致。
- **长代码块：PASS。** 展开的 smoke 命令完整可见、等宽字体与深色背景对比良好；HTML 对 `pre` 设置 `white-space: pre-wrap`、`overflow-wrap: anywhere` 与 `overflow-x: auto`，折叠区中的更长命令不会造成页面级横向溢出。
- **横向溢出和截断：PASS。** 全页截图左右边界完整，正文始终位于 1180 px 内容容器内；导航仅在自身容器允许横向滚动。未见页面级横向滚动、文本裁切、卡片越界、图形截断或页脚缺失。

## 非阻塞观察

- Dk112 双栏区域因右侧四级 Gate 时间线较高，左侧卡片下半部留白较大；这是版面节奏问题，不影响信息完整性或可读性。
- Manifest / audit 哈希采用 12 px 辅助字号；当前桌面交付下可接受，如未来把截图缩小嵌入文档，可考虑提高到 13 px。

## 结论

当前 Report 模式交付件在桌面全页渲染下没有阻塞性视觉缺陷，可交付。
